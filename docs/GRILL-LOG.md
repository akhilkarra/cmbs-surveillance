## Research findings that constrain decisions (2026-10-24; details in `research/20`–`23`)

**Jev (checked against docs.typesafe.ai):**
- One endpoint. Question types `choice` (≤255 options), `score` (≤10 levels) and `noul` (yes/no).
- **No evidence or spans in the response, no seed, no local option.**
- The confidence score isn't claimed to be calibrated, and repeated calls vary slightly (TypeSafe's own test).
- Pin the version (`jev-1.14.0`, not `jev-latest`). Access status is unclear.

**Stack:**
- **Architecture:** one Python package with a core, a Typer CLI and a FastAPI server. Skills call the CLI. React is generated from the committed OpenAPI schema via orval.
- **Perspective** moved to `@perspective-dev` and adds about 4.9 MB of WebAssembly; AG Grid + lightweight-charts is preferred.
- **New majors:** DuckDB 2.0 LTS (10-21) and Polars 2.0 (10-06), validated locally with Pandera 0.34.1.
- **behavex ≥ 4.6.8** (older versions have destructive bugs).
- **Type checking:** pyright (ty is beta).
- **Lean:** core 4.35.0, no Mathlib needed. All three theorems proved locally.

**Enforcement:**
- Hooks and permissions are enforced; CLAUDE.md is advisory.
- Edit blocks can be bypassed through scripts or shell indirection, so protected files also need a CI hash check plus an `Approved-by:` line in the commit.
- Lean: `lake build --wfail`, and `#print axioms` must reject `sorryAx` and the axiom `native_decide` adds.

**Gaps none of the three trust layers cover:**
1. An exact check of every piece of evidence against the source.
2. A replay cache of recorded model calls.
3. A golden set with confidence intervals.
4. Abstention into a review queue.
5. Text-vs-tape cross-check flags.
6. An as-of join on filing date.
